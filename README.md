# Protocolo de solicitação: Ferritina e Vitamina B12

Painel do Laboratório (SADT) da São Cristóvão Saúde com a análise dos pedidos de ferritina e vitamina B12 de janeiro a outubro de 2026, para apoiar a proposta de protocolo de solicitação.

## Como abrir

- **Pelo GitHub Pages:** em *Settings → Pages*, escolha a branch `main` e a pasta `/ (root)`. O painel fica em `https://douglasraphael.github.io/Protocolo-Vitamina-B12-e-Ferritina/`.
- **No computador:** baixe o `index.html` e abra no navegador. Não precisa de internet.

Funciona no computador e no celular.

## O que tem no painel

Uma aba para cada exame (Ferritina e Vitamina B12), com:

- gasto por ano, preço unitário, exames realizados e pacientes atendidos;
- repetição: quantos pacientes repetem, o intervalo entre os exames e o que fica abaixo do intervalo mínimo;
- exames por paciente no período;
- simulador:
  1. trava por intervalo mínimo (90 dias para ferritina, 180 dias para B12), calculada com dados reais;
  2. redução adicional com justificativa obrigatória, que é uma estimativa;
- gasto por mês, distribuição por idade e evidências científicas.

## Observações

- Preços usados: ferritina R$ 22,81 e vitamina B12 R$ 15,51, aplicados a todo o período. Valores anuais = 10 meses × 12/10.
- A base não separa pedidos da rede própria e da rede externa. Os valores de economia são o máximo possível, considerando toda a demanda sob o protocolo.
- Os dados estão agregados, sem nomes de pacientes ou de médicos.
